# Gas Cat – Sistema de Gestión de Distribución de Gas

## Descripción
**Gas Cat** es una aplicación web diseñada para gestionar la distribución y venta de gas en la ciudad de **Xalapa, Veracruz**. El sistema permite a administradores, vendedores y clientes interactuar de manera eficiente y segura, asegurando que cada usuario tenga acceso únicamente a las funcionalidades que le correspondan según su rol.

## Roles del sistema

### Administrador
- Control total del sistema.  
- Gestiona clientes, vendedores, unidades, rutas, pedidos y ventas.  
- Puede generar reportes y cortes de caja diarios.

### Vendedor
- Encargado de la distribución de gas.  
- Consulta rutas y pedidos asignados.  
- Registra ventas externas y atiende pedidos de manera operativa.

### Cliente
- Usuario final que puede registrarse en el sistema.  
- Gestiona su perfil.  
- Realiza pedidos de gas para entrega.

## Funcionalidades principales
- Registro, consulta y edición de clientes, vendedores, unidades y rutas.  
- Creación, asignación y atención de pedidos, tanto internos como externos.  
- Registro y consulta de ventas, generación de cortes de caja y reportes de ventas descargables.  
- Inicio y cierre de sesión seguro, con control de sesiones activas.  
- Gestión de perfiles de usuarios con edición y consulta de información personal.

## Objetivo
El sistema busca optimizar la operación de la distribución de gas en Xalapa, permitiendo un control eficiente de pedidos, rutas, ventas y usuarios, mientras garantiza seguridad, confiabilidad y una experiencia intuitiva para todos los roles del sistema.
